# Unicorn Model

The **Unicorn Model** is a high-confluence ICT execution model built from the same components emphasized in the 2022 mentorship order-block material: daily bias, killzone timing, liquidity raid, market structure shift, and a qualifying order block / fair value gap entry.

## Core idea

This wiki uses "Unicorn Model" as a synthesis label for the Episode 18-style stack rather than as a separate mechanical indicator.

The practical expectation is:

1. establish daily bias,
2. identify a liquidity pool that can be raided,
3. wait for displacement and market structure shift,
4. require an order block and/or fair value gap for entry,
5. execute inside the correct killzone,
6. avoid late fills or outside-window entries.

## Components

- **Daily bias** — determine the expected draw first.
- **Liquidity sweep** — price raids a nearby pool.
- **Market structure shift** — the raid is confirmed by structural delivery away from the sweep.
- **Order block** — the delivery-change area used for the retest / entry.
- **Fair value gap** — the imbalance used to refine the entry.
- **Killzone** — the timing window that makes the model actionable.
