# 9:50 Macro + ATM Model | ICT Tape-Read

This clip presents a 9:50–10:10 macro-style setup built from higher-time-frame analysis and an external-to-internal liquidity frame.

The practical message is that the time window matters as much as the setup logic. The model is described as bread-and-butter because it combines a timed execution pocket with a clear directional map, rather than hunting trades all morning.

It is best treated as a macro-window bridge example: the clip shows how a tape-read trader uses the morning window, higher-time-frame context, and external-to-internal flow to set up a live trade.
