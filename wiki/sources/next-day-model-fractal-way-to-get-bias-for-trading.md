# Next Day Model - Fractal Way To Get Bias For Trading

## Summary

- The clip defines a next-day bias method by reading the previous candle: a failed close outside the range suggests the next candle may continue or reverse in the opposite direction.
- The same logic is used fractally across daily and hourly charts, so the higher-time-frame candle close becomes the first bias filter before any lower-time-frame execution.
- After a run of expansion candles, the model expects a phase change into retracement, consolidation, or reversal, which is why the prior day / prior candle matters so much.
- This is best treated as a premarket bias scaffold: it tells you which side to expect next, not a standalone entry trigger.
