# First Presentation Model #1 scalping

## Summary

- Presents a scalping model built around the first presentation FVG concept, with the entry focused on minor buy-side / sell-side inefficiencies in the active morning range.
- The model uses 15-minute or 5-minute inefficiencies as the starting frame, then waits for the first minute FVG after 9:30 to appear as the actual presentation.
- The entry is supposed to sit inside the first presentation gap, with the 50% line treated as the best technical anchor.
- Targets are deliberately modest: minor inefficiency fills, scalp-size expansions, or the nearest liquidity checkpoint rather than a huge swing objective.
- The speaker stresses one-way order flow and notes that the method can be fractalized down to 15-second charts for tighter entries.
- Logging time / day / screenshot evidence is part of the process; the model is built by tracking recurring conditions.
- This source is best treated as a source-specific scalping example of the broader [[models/first-presentation-model]] rather than a separate doctrine family.
