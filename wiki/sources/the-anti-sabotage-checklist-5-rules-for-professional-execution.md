# The Anti Sabotage Checklist: 5 Rules for Professional Execution

This clip argues that self-sabotage is a pattern problem, not a willpower problem. The fix is to build friction between impulse and action so the rational mind can catch up before the trader clicks.

The five practical interruptions are: a delay before touching the mouse, a premortem that assumes the trade can fail, a physical anchor that breaks autopilot, a one-bullet mindset that removes the illusion of endless chances, and an external auditor test that filters out trades you cannot explain.

The larger takeaway is that sabotage becomes much easier to manage when the trader designs the environment so the default response is pause, review, and only then decide.
