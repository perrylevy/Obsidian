# Calub's Model "Conceptually" - Variant #1

## Summary

- The model is a conceptual framework for an intraday buy/sell plan that uses a small number of recurring building blocks rather than a large discretionary checklist ([[sources/calubs-model-conceptually-variant-1]] @ 2:14, @ 2:43).
- The Asian high and low are marked after the 2:00 a.m. New York close, and the first side taken sets the directional bias only after the opposite side is also taken ([[sources/calubs-model-conceptually-variant-1]] @ 2:25, @ 3:42, @ 5:52, @ 7:20).
- Entries come after a market-structure shift or, if that never appears, after a double-sweep and acceptance back into the range on the retest ([[sources/calubs-model-conceptually-variant-1]] @ 6:14, @ 6:46, @ 7:38).
- The framework explicitly uses a bullish FVG buy limit at the high of the gap plus one tick, a stop below the low, and a first partial / terminus tied to Fibonacci extension levels overlapping NDOG or NWOG ([[sources/calubs-model-conceptually-variant-1]] @ 4:02, @ 4:58, @ 6:31, @ 8:23).
- The working window is framed as 7:00–11:00 a.m. Eastern, with the first 30 minutes of each hour emphasized and 9:30 treated as the main opening bell context ([[sources/calubs-model-conceptually-variant-1]] @ 3:29, @ 9:05).
- This is best read as a framing example: it packages the same opening-range / liquidity / FVG logic into a compact model rather than introducing a wholly separate doctrine family.
