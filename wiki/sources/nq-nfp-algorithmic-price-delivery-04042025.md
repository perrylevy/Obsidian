# 2025 Lecture Series - NQ NFP Algorithmic Price Delivery 04/04/2025

## Summary

- Uses the NFP / 10:00-timeframe price action as a proof of the price-delivery-continuum idea: the first post-open FVG after a short-term buyside liquidity run becomes the usable bearish array.
- Treats the 9:30–10:00 opening range as the first live scaffold, then uses the 9:50–10:10 macro to capture the repeatable short continuation.
- Shows a second phase at 10:50–11:10 where price returns into the inversion FVG and touches the wick high that had been flagged as the discounted target.
- Extends the same logic into the PM session: the 1:30–2:00 opening range, the 3:15–3:45 macro, and the consequent encroachment of the PM first-presented FVG.
- Distinguishes a true liquidity void from a normal inefficiency: a real void is an actual empty pocket / common gap, not just any gap with traded prints.
- Uses the daily wick / prior highs and lows as the larger draw-on-liquidity frame while the quarter-hour windows control the actual entry timing.
