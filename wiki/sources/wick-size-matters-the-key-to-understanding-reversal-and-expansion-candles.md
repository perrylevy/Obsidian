# Wick Size Matters: The Key to Understanding Reversal and Expansion Candles

## Summary

- Expansion candles have small wicks on both sides and a large body; the candle makes its low or high early and leaves time to expand.
- Reversal candles use most of the candle range to make a large opposing wick, so the trade should be framed back toward the open or nearby liquidity rather than assuming more expansion.
- If the wick is large, the source favors waiting for the next candle — the candle-3 continuation — where a smaller wick plus a delivery change supports expansion.
- On the higher-timeframe examples, a shallow opposing run combined with change in state of delivery supports expansion, while a large opposing run without confirmation argues for a target back toward the daily open.
- The main execution lesson is wick-size filtering: small opposing run = expansion candidate; large opposing run = wait for confirmation or use the open as the target.
