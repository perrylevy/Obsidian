# Judas Swing

A deliberate **counter-move against the directional bias**, engineered at session open or 8:30 NY, designed to trap retail before the true move ([[sources/2024-04-18-ob-tape-reading]] @ 1:19:07, @ 1:39:08, @ 1:43:09).

## Pattern

The 04/29/2024 bias lecture gives a clean pre-news version: when the higher-time-frame / seasonal read is bearish and a red-folder release is coming, ICT wants to see an early probe below a short-term low to trigger breakout shorts, then a rally after the release that rips those shorts before the true move continues. That is the Judas swing mechanic in live tape form ([[sources/how-to-read-price-with-or-without-a-bias-april-29-2024]] @ 31:39–32:24, @ 38:37–39:24, @ 43:04–45:14).
If the HTF / daily bias is **bearish**, expect an up-spike (Judas swing) into a premium PD array before the real drop. Mirror for bullish bias.

Episode 19 makes the fractal point explicit: multiple Judas swings can occur at different timeframes, so the term is not limited to one open or one session window ([[sources/2022-ict-mentorship-episode-19]]).

ICT's confirmation phrase when the Judas swing reaches the identified premium array: **"done enough for me"** — the trap is set, entry can be considered ([[sources/2024-04-18-ob-tape-reading]] @ 1:43:09).

The April 29, 2024 bias lecture gives the same idea a macro-week overlay: on FOMC / NFP weeks, the pre-news push is just the staged fake run, and the trader should read it as part of the larger bias-building process rather than as a standalone signal ([[sources/how-to-read-price-with-or-without-a-bias-april-29-2024]] @ 26:52, @ 31:39–32:24, @ 38:37–39:24, @ 43:04–45:14).

## Distinction from generic stop-hunt

Judas swing is **time-anchored** (open / 8:30 NY) and **bias-aware** — it's the algorithmic counter-move staged at a specific time, not a random sweep at any swing point. Generic [[concepts/liquidity-sweep|liquidity sweeps]] occur whenever stops cluster.

## SMC synonym

SMC's **inducement** — the engineered pool taken before the real move — is the same idea as the Judas swing when it occurs at a session open or news time. The canonical term for the phase is [[concepts/manipulation|manipulation]]; PO3 uses it as the phase-two delivery label, while the session-timed instance is **judas-swing**. No separate inducement page.
