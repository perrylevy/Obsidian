# Rule Adherence

Rule adherence is the habit of following a trading system exactly as written instead of improvising when money and emotion are active.

The practical lesson is that a profitable system is only profitable if it is actually executed consistently. Entry rules, exit rules, position sizing rules, and trade-management rules all need to be defined in advance and then followed mechanically.

## Core idea

A trader does not have an edge just because a strategy exists on paper. The edge only survives when the trader obeys the system on every qualifying setup and does not override it with hope, fear, ego, or discretionary “gut” calls.

The self-sabotage clip is a reminder that rule-breaking is often a coping move rather than a pure logic error. If the trader is breaking plan after a loss, the first task is to address the emotional state that is pulling them away from the rules.

The "This Speech By ICT Hits!" clip adds a motivation-layer version of the same rule: stay with one model, do the boring work, and trust the process long enough for repetition to become evidence. In other words, rule adherence is not just a chart skill; it is a lifestyle choice about how you spend your time and attention ([[sources/this-speech-by-ict-hits-ict-2024-mentorship-motivation]]).
The anti-sabotage checklist source adds the operational version of that same lesson: build friction around impulse, slow the click, and make the default action pause / review / decide instead of immediate execution ([[sources/the-anti-sabotage-checklist-5-rules-for-professional-execution]]).

## Practical supports

Common ways to support rule adherence include:

- backtesting until the system is trusted,
- forward testing before risking real money,
- using a pre-trade checklist,
- journaling whether the rules were followed, not just whether P&L was positive,
- and redefining success as perfect execution rather than short-term profit.
