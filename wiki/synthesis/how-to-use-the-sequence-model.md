# How to Use the Sequence Model

The sequence model is a top-down bias workflow that builds a trade narrative across multiple time frames. The practical idea is simple: start with the highest relevant target or key level, then wait for the stop run, closure, and continuation structure that moves the market into distribution.

## Core idea

The sequence is a way to avoid forcing a trade before the market has shown its intent.

Typical progression:
1. Define the higher-time-frame target or key level.
2. Wait for the higher-time-frame stop run / manipulation.
3. Require a candle closure that confirms the change in delivery.
4. Drop to the execution timeframe.
5. Use the FVG / order block / SMT context for the entry.
6. Hold for the next liquidity objective.

## What the sequence tells you

- whether the market is accumulating, manipulating, or distributing,
- which side is likely to be drawn on next,
- and when the lower-time-frame entry is actually safe to take.

## Practical use

The source's key edge is that it lets you stay aligned with the larger distribution narrative across multiple time frames.

Use it when:
- monthly or weekly structure is clear,
- a session or daily key level is obvious,
- and you want a cleaner way to map entry timing to the higher-time-frame draw.
