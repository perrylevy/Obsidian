# How to Build Daily Bias

This page is the parent map for the wiki's daily-bias material. The goal is to stop the vault from treating bias as several unrelated mini-systems.

## Canonical sequence

1. Start with the higher-time-frame frame:
   - [[concepts/price-delivery-continuum]]
   - [[concepts/pd-array]]
   - [[concepts/discount-premium]]
   - [[concepts/draw-on-liquidity]]
2. Decide whether the market already has a directional draw or whether it is still unresolved:
   - [[concepts/daily-bias]] — directional thesis: will price draw to old high or old low?
   - [[concepts/daily-profile]]
   - [[timing/nightly-premarket-bias]]
   - [[timing/no-initial-bias]]
3. Hand off to the session structure that will confirm or deny the idea:
   - [[concepts/opening-range]] — the span from open to high/low that defines where premium/discount arrays form
   - [[timing/first-hour-dealing-range]]
   - [[timing/first-presented-fvg]]
   - [[timing/macros]]
4. Only then choose the entry model:
   - [[models/power-of-three]]
   - [[models/silver-bullet]]
   - [[models/turtle-soup]]

## Bias is not one thing

In this wiki, daily bias can come from several layers working together:

- higher-time-frame PD-array location
- active liquidity draw
- session profile and event calendar
- whether the open is clear or still unresolved
- whether the first presented displacement validates the idea

That means "daily bias" is best treated as a synthesis page, not as a single stand-alone concept.
